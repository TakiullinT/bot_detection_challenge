# Классификация и детекция ботов по cookie (Cookie Bot Classification & Detection Pipeline)

Репозиторий содержит высокопроизводительный пайплайн машинного обучения полного цикла (End-to-End), предназначенный для обнаружения и классификации ботов на основе логов событий кук и телеметрии пользователей. Решение использует передовую инженерию признаков с помощью **Polars** и оптимизированный ансамбль моделей **LightGBM**, **CatBoost** и **XGBoost**.

---

### 🏆 Результаты

* **Метрика:** Precision при Recall $\ge 70\%$ ($P@R \ge 0.70$)
* **Локальный OOF-скор ансамбля:** **0.7447** (значительно превосходит отдельные модели)
* **Выходные данные:** Генерирует готовый файл `submission.csv`, содержащий 4,909 предсказаний, полностью готовых к отправке.

---

### 🚀 Ключевые особенности и подход

#### 1. Высокопроизводительная инженерия признаков (Polars)

Используя ленивые вычисления (`lazy evaluation`) и быструю агрегацию в `Polars`, пайплайн извлекает **67 мощных признаков** из сырых событий:

* **Временные дельты и паттерны ботов:** Вычисление временных интервалов (`dt`) между последовательными событиями, выделение циклов ультрабыстрого выполнения (`dt < 20мс`), действий с нулевой задержкой (`dt == 0`) и аномалий ритма.
* **Физика курсора:** Отслеживание метрик движения мыши с использованием евклидового расстояния, скорости, ускорения и площади ограничивающего прямоугольника (`pointer_bbox_area`) для разделения человеческого поведения и автоматических парсеров.
* **Глубина поиска и навигации:** Агрегация частот поисковых страниц, уникальных категорий товаров, количества локаций и разнообразия поисковых запросов.
* **Текстовая и категориальная обработка:** Нативный текстовый анализ строк User-Agent на наличие ключевых слов ботов (`headless`, `selenium`, `puppeteer`, `crawler` и т.д.) в сочетании с частотным кодированием (`frequency encoding`).

#### 2. Стратегия валидации

* **5-кратная стратифицированная кросс-валидация** (`StratifiedKFold`, $seed=42$): Сохраняет исходное распределение целевого класса по фолдам, обеспечивая стабильное обучение и надежную оценку Out-Of-Fold (OOF) без утечки данных (`data leakage`).

#### 3. Архитектура моделей и блендинг

Ансамбль из трех передовых фреймворков градиентного бустинга:

* **LightGBM:** Быстрый численный решатель деревьев с надежными гиперпараметрами (`max_depth=7`, `num_leaves=63`).
* **CatBoost:** Использует нативную обработку текстовых признаков для строк `top_user_agent`.
* **XGBoost:** Обеспечивает комплементарные границы решающих правил для числовых агрегаций.
* **Оптимизация весов методом Grid Search:** Систематический поиск по сетке весов для нахождения оптимальных коэффициентов блендинга (`LGBM=0.460`, `CatBoost=0.394`, `XGBoost=0.146`), максимизирующих целевую метрику напрямую на OOF-предсказаниях.

### ⚙️ Требования и установка

Убедитесь, что у вас установлены все необходимые библиотеки Python:

```bash
pip install numpy pandas polars scikit-learn lightgbm catboost xgboost

```

---

### ▶️ Как запустить

1. Убедитесь, что файлы датасета (`train.csv`, `test.csv`, `events.csv.gz`) находятся в директории `data/`.
2. Запустите основной скрипт пайплайна:

```bash
python solution.py

```

Скрипт выведет пошаговый прогресс, OOF-скоры валидации, оптимальные веса ансамбля и создаст файл `submission.csv`.
